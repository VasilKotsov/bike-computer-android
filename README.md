# Bike Computer Android

This repository contains the initial milestone for an independent Android bike-computer app.

## Current milestone

- Compose-based bike computer home screen
- Bluetooth permission handling for BLE scanning
- BLE sensor discovery and service listing
- Device detection for speed/cadence and heart-rate services
- App state handling for denied permissions, disabled bluetooth, and scan failures
- Unit tests for device identification logic
- Research and architecture notes for the bike-computer project

## Notes

This first milestone focuses on BLE discovery and device visibility. It does not yet implement GPS ride recording, training analytics, or saved ride history.
